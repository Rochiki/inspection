## Untuk petugas lapangan & supervisor (HP)

### Pertama kali

1. Buka link aplikasi dari QSHE di **Chrome**.
2. Tekan menu **⋮ → Instal aplikasi**. Ikon **Temuan QSHE** akan muncul di layar HP.
3. Buka aplikasinya sekali saat ada sinyal. Setelah itu aplikasi bisa dipakai tanpa internet.

### Mencatat temuan

1. Tab **Catat → Inspeksi baru**. Pilih area, isi tanggal dan nama inspector.
2. Pilih **Temuan** atau **Good practice**.
3. Ambil foto (maksimal 4). Foto pertama akan dipakai di slide laporan.
4. Isi **Lokasi spesifik**, misalnya *rak APD workshop*.
5. Tulis **catatan singkat** apa adanya, boleh pakai singkatan. Contoh: *kabel panel terkelupas, colokan ditumpuk2 pake roll kabel*.
6. Tekan **Rapikan tanpa AI**. Aplikasi menyusun judul, deskripsi baku, tingkat temuan, klausul, dan regulasi.
7. **Periksa hasilnya.** Hasil ini dari aturan kata kunci, jadi koreksi kalau ada yang kurang pas.
8. Tekan **Kirim ke Supervisor**.

### Persetujuan supervisor (di lokasi)

1. Tab **Temuan**, lalu buka entri yang berstatus *Menunggu Supervisor*.
2. Isi **nama supervisor**, lalu tekan **Setujui (Supervisor)**. Kalau ada yang perlu diperbaiki, tulis catatan lalu tekan **Kembalikan ke pencatat**.

### Mengirim ke QSHE

1. Setelah inspeksi selesai, buka tab **Laporan** dan pilih inspeksinya.
2. Tekan **Unduh paket data (.json)**. File tersimpan di folder **Download** HP.
3. Kirim file itu ke QSHE lewat WhatsApp/email, atau unggah ke link OneDrive QSHE.
4. Untuk laporan cepat di grup WhatsApp, tekan **Salin ringkasan teks**, lalu tempel.

> ⚠️ Data tersimpan di HP Anda sampai dikirim. **Jangan hapus data Chrome atau uninstall aplikasi** sebelum paket data terkirim.

## Untuk QSHE & safety manager (laptop)

### Persiapan (sekali)

1. Buka link aplikasi di **Chrome/Edge**, lalu klik **Instal** di kolom alamat.
2. Buka **Pengaturan → Folder penyimpanan → Pilih folder**, lalu pilih folder di OneDrive, misalnya `OneDrive\QSHE\Temuan Lapangan`. Setelah terhubung:
   - database dan foto tersinkron otomatis ke `…\Database\`;
   - PowerPoint dan Excel tersimpan ke `…\Laporan\`.
3. Buka **Pengaturan → Perangkat QSHE → Aktifkan mode QSHE**, lalu buat PIN. Hanya perangkat ini yang bisa memberi **Final**.
4. Di Pengaturan, isi daftar **supervisor**, **area**, dan **PIC**, lalu tekan **Simpan pengaturan**.

> Laptop QSHE lain yang memilih folder OneDrive/SharePoint yang sama akan melihat data yang sama. Kalau browser meminta izin folder lagi, ketuk tulisan status di kanan atas.

### Menerima dan memfinalkan temuan

1. **Pengaturan → Impor paket data dari lapangan**, lalu pilih file `.json` kiriman lapangan. Entri yang sudah disetujui supervisor langsung masuk antrean **Menunggu QSHE**.
2. Tab **Temuan**, lalu buka entri dan periksa klausul, tingkat temuan, serta deskripsi.
3. Tekan **Setujui jadi Final (QSHE)**. Kalau perlu perbaikan, tulis catatan lalu tekan **Kembalikan ke Supervisor** atau **Kembalikan ke pencatat**.
4. Isi **tindak lanjut** (akar masalah, tindakan, PIC, batas waktu) saat sudah ditetapkan bersama PIC.

### Membuat laporan

1. Tab **Laporan**, lalu pilih inspeksi.
2. Tekan **Susun otomatis** untuk kesimpulan dan rekomendasi, lalu lengkapi sendiri.
3. Tekan **Unduh PowerPoint** atau **Unduh Excel**. File langsung tersimpan di folder OneDrive `…\Laporan\`.

Laporan yang masih berisi entri belum Final akan diberi tanda **DRAFT**.

## Tingkat temuan

| Tingkat | Artinya | Contoh |
|---|---|---|
| **Critical** | Potensi cedera berat/fatal, pelanggaran regulasi berisiko sanksi, atau pencemaran signifikan. **Hentikan pekerjaan.** | Bekerja di bawah unit tanpa jack stand, LOTO tidak dipasang, oli mengalir ke selokan |
| **Major** | Potensi cedera ringan, peringatan regulator, atau gangguan operasional | APAR kedaluwarsa, kabel rusak, limbah B3 tanpa label |
| **Minor** | Dampak minimal | Housekeeping kurang rapi, rambu pudar |

Tingkat temuan dari tombol Rapikan hanya **usulan**. Keputusan akhir ada di supervisor dan QSHE.
